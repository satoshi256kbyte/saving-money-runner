# Saving Money Runner プロダクト概要

セキュリティと継続的統合・継続的デリバリー（CI/CD）を両立させるGitHub Actions用のセルフホステッドランナーソリューション。

## プロジェクトの使命

GitHub標準のランナーよりも格安かつ高性能な環境を、企業のセキュリティ要件を満たしたまま提供する。
エンタープライズの厳格なセキュリティ監査に耐えうる設計と、自動化された運用を実現することで、
開発チームが安心してAI駆動開発に集中できるインフラ基盤を構築する。

## ターゲット

国内エンタープライズ企業の情報システム部門およびマネージャー層。
以下の課題を抱える組織を対象とする。

- AI活用による開発の高速化とともに、CI/CD実行時間と従量課金コストが増大している
- セキュリティと開発プロセス改善に十分なリソースを割けない環境
- 情シス監査により厳格なガバナンス要件の遵守が必要

## システムのコア価値

| 価値提案 | 実装手段 |
| --- | --- |
| **セキュアなインフラ** | VPC分離、最小権限IAM、監査ログ取得を標準構成に組み込み |
| **導入の簡単さ** | ワンクリックデプロイスクリプトと最小限の設定変更 |
| **高いコストパフォーマンス** | AWS スポットインスタンス活用で GitHub 従量課金を大幅削減 |
| **運用負荷の最小化** | セキュリティパッチ、ランナー台数調整など運用工程を完全自動化 |

## 主要な機能

### 1. GitHub App による安全なイベント処理

顧客のGitHub Organization内に限定されたPrivateアプリを配置。
GitHubからのジョブ実行イベント（Push、PR、Workflow dispatch等）をWebhookで受け取り、
HMAC署名検証を経た後、短命な認証トークンを発行して安全にランナーを登録する。

最小権限原則に従い、要求権限をランナー実行に必要な範囲のみに制限。

### 2. エフェメラル・ランナーの動的プロビジョニング

AWS EC2スポットインスタンス＋Auto Scaling Groupを活用し、
ジョブ実行イベントをトリガーとして動的にランナーをプール内から起動。

| 特性 | 詳細 |
| --- | --- |
| **ライフサイクル** | 1ジョブごとに使い捨て（環境汚染を防止） |
| **配置** | Private Subnet 内のパブリック IP なし |
| **通信制御** | API Gateway + AWS Lambda による署名検証 |
| **スケーリング** | Auto Scaling により台数を自動調整 |

### 3. AMI の定期最新化とセキュリティスキャン

Amazon EC2 Image Builder を用いて月に1回（または重大脆弱性発見時に即時）、
ランナー用AMIをOS ハードニング、セキュリティパッチ適用のうえ再構築。

| プロセス | 内容 |
| --- | --- |
| **ビルド** | 最新のOSイメージから定期的にAMI生成 |
| **スキャン** | 脆弱性スキャンツールで安全性を検証 |
| **承認** | セキュリティ要件を満たすAMIのみを配布 |
| **ローリング更新** | ランナープール上で段階的にアップデート |

## 導入フロー

エンドユーザーが実施する手順は以下の3ステップに集約。

1. **インフラのデプロイ** - AWS CDKアプリの実行で AWS リソースを自動構築
2. **GitHub アプリの登録** - IaC により Private App、Webhook、シークレット管理が自動完了
3. **ワークフロー設定の変更** - `runs-on: saving-money-runner` の1行変更のみ

## セキュリティの原則

- **IAM 最小権限** - ランナーと各 AWS サービス間の通信に必要な権限のみを許可
- **通信の暗号化** - VPC 通信、API Gateway（HTTPS）、Secrets Manager による機密管理
- **ネットワーク隔離** - Private Subnet でのランナー稼働により外部からの直接アクセスを防止
- **監査ログの標準装備** - CloudTrail で全操作を記録し、情シス監査に対応

## 提供形態と拡張性

本システムは検証済みの IaC テンプレートとして、
以下の形態でエンタープライズ顧客へ提供可能。

- セキュリティホワイトペーパーとセットでの直接デプロイ
- AWS マーケットプレイス経由での配布
- プロフェッショナルサービスと併用したオンサイト導入支援

将来的には GitLab CI/CD、Jenkins 等の他の CI/CD プラットフォーム対応も検討。
